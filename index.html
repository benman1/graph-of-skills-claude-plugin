Graph-of-Skills for Claude Code

Connects Claude Code to Graph-of-Skills and adds one short skill. The skill tells your agent to check for a written method before a task in an unfamiliar file format, tool or convention.

1. Get a key

Create a free API key at akilima.tech/get-api-key, then add it to your shell profile:

export GOS_API_KEY=your_key_here

2. Install the plugin

claude plugin marketplace add benman1/graph-of-skills-claude-plugin
claude plugin install graph-of-skills@akilima

The plugin declares the MCP server. It reads your key from GOS_API_KEY, so the key is never written into a config file.

Only want the skill?

npx skills add https://www.akilima.tech -g -a claude-code -y

What happens on a task

  • Your agent sends one sentence describing the task to Graph-of-Skills.
  • Graph-of-Skills searches a public skill catalog and your own skills, by exact words and by meaning.
  • It returns the best matches with their full text, cut to a size limit you can set.
  • The agent follows the one that fits. Nothing is installed on your machine.
